# Análise Visual Detalhada - Lovable vs Landing Atual

## Principais Diferenças Identificadas

### 1. HERO SECTION

**Lovable:**
- Background com padrão hexagonal sutil (cor creme/bege claro)
- Badge "Análise Preditiva e Estatística" com borda arredondada, fundo claro, ícone amarelo
- Título: "397 mil" em cor marrom/terracota (itálico/serif), "restaurantes fecharam em 2024." em preto
- Subtítulo: "1 em cada 12 fecha este ano. **Não seja o próximo.**" (negrito no final)
- Descrição mais curta e direta
- Botões: "Começar Grátis" (marrom sólido com seta), "Ver Demonstração" (outline com ícone play)
- Features abaixo dos botões com ícones de check verde

**Atual:**
- Background mais simples
- Badge similar mas com estrela
- Título com "397 MIL" em destaque grande separado
- Descrição mais longa

### 2. MÉTRICAS (40%, 3x, 100%)

**Lovable:**
- Números grandes em cores diferentes (40% laranja, 3x cinza, 100% coral/vermelho)
- Texto descritivo pequeno abaixo
- Layout horizontal limpo
- Fonte mais fina/elegante

**Atual:**
- Cards com bordas
- Layout diferente

### 3. SEÇÃO "O PROBLEMA"

**Lovable:**
- Título: "Não é falta de clientes. É falta de controle."
- Subtítulo explicativo
- Cards de estatísticas com ícones coloridos (vermelho, amarelo, laranja, azul)
- Card de alerta vermelho destacado: "CMV acima de 36% significa -11,84% de lucro"

### 4. SEÇÃO "A SOLUÇÃO"

**Lovable:**
- Grid de 6 cards com ícones coloridos
- Design mais limpo e minimalista
- Ícones em círculos coloridos

### 5. CALCULADORA

**Lovable:**
- Slider visual para CMV (não apenas input)
- Marcadores de 20%, 38%, 60%
- Design mais interativo

### 6. PLANOS

**Lovable:**
- 4 planos: Pawn, Knight, Rook, Chess
- Preços: Grátis, R$ 97/mês, R$ 197/mês, Sob consulta
- Cards com listas de features
- Badge "Mais Popular" no Rook
